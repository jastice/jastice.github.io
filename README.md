# jastice.github.io

Redirects to [justinkaeser.com](https://justinkaeser.com/). The site itself lives in [jastice/justinkaeser.com](https://github.com/jastice/justinkaeser.com).

Every page here, including `404.html`, sends the visitor to the home page there. Project sites (`jastice.github.io/<repo>/`) are served from their own repositories and are not affected.

There is deliberately no custom domain set on this repository: that would move the project sites to justinkaeser.com too, which is not hosted on GitHub Pages.
